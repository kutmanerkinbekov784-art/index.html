Четвертные оценки

Укажи предмет в поле над сообщением, напиши оценки через пробел или попроси посчитать всё. Можно прикрепить фото дневника.

Привет! Напиши оценки через пробел или прикрепи фото из галереи/камеры. Название предмета укажи в поле над строкой сообщения. Чтобы посчитать дневник целиком, напиши «Посчитай всё».

Фото обрабатывается в этом браузере и не отправляется ИИ-сервису. Перед подсчётом проверь распознанные оценки. Для повышения предполагается, что следующие оценки будут целевого балла.

Оценки в колледже

Посчитай баллы за семестр и экзамен по правилам своего предмета.

Не нужно складывать баллы самому: перечисли полученные баллы через пробел, и сайт сложит их. Если в журнале уже есть итоговая сумма, просто введи одно число. Итог будет пересчитан в проценты из 100. Пороги оценок возьми из силлабуса своего предмета.

Перечисли все баллы за семестр через пробел. Например, «8 7 10 9» сайт сам сложит. Баллы за экзамен можно тоже перечислить через пробел; пустое поле означает 0.

Значения 60 и 40 — только пример распределения баллов. Если у тебя другое, замени максимумы по силлабусу.

Пороги оценок по твоему колледжу

Заполни минимальный итоговый балл для каждой отметки. Например, если по силлабусу для «3» нужно не меньше 56 баллов, введи 56. Это только пример — не общая шкала для всех колледжей.

Помощник по учёбе

Привет, ученик или студент, я твой ИИ-помощник по учёбе. Разберём задачу так, чтобы ты понял тему и смог решить похожие сам.

Проверяю подключение…

Напиши условие задачи и предмет. Я объясню решение по шагам и помогу разобраться.

Можно выбрать JPG, PNG или WebP до 3 МБ. Камера откроется только после нажатия; браузер или устройство могут запросить разрешение. Фото отправится помощнику для ответа и не сохраняется сайтом.
