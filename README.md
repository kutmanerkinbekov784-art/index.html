# Помощник по учёбе

Статический сайт для GitHub Pages с калькулятором четвертных оценок, распознаванием оценок на фотографии и учебным ИИ-помощником. Для входа используется Supabase Auth, а запросы к Gemini проходят через защищённую Supabase Edge Function.

## Настройка перед публикацией

Для реальной регистрации и работы ИИ понадобятся свои проекты Supabase и Google AI Studio. Пока они не настроены, на сайте будут доступны четвертные оценки, а учебный раздел покажет, что подключение не настроено. Не отправляй ключи и пароли в чат или репозиторий.

### 1. Подключи уже созданный проект Supabase

1. Второй проект создавать не нужно. Открой свой проект в [Supabase](https://supabase.com/).
2. Найди **Project URL** в **Project Settings → API** и публичный **Publishable key** в **Project Settings → API Keys** (или используй legacy **anon key** в **Project Settings → API**). Это два публичных значения для браузера. **Не используй** ключи `service_role` и `secret`.
3. Открой `config.js` в этом репозитории: вставь Project URL вместо `https://YOUR_PROJECT_ID.supabase.co`, а Publishable/anon key — вместо `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY`. Эти значения будут доступны посетителям опубликованного сайта — это нормально для публичного ключа. Не вставляй сюда ключ Gemini или другие секреты.
4. В Supabase открой **Authentication → URL Configuration** и задай адрес GitHub Pages сайта как **Site URL**, а также добавь его в **Redirect URLs**. Обычно адрес выглядит как `https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/ИМЯ_РЕПОЗИТОРИЯ/`. Включи вход по Email. Если включено подтверждение почты, пользователь должен подтвердить адрес до входа.

### 2. Подключи Gemini на сервере Supabase

1. Получи отдельный API key в [Google AI Studio](https://aistudio.google.com/apikey).
2. В уже созданном проекте Supabase открой **Edge Functions → Secrets** и добавь секрет с точным именем `GEMINI_API_KEY`, вставив туда ключ Google. Вводи его только в настройках Supabase — не присылай в чат и не добавляй в `config.js`, HTML, браузерное хранилище или Git.
3. Установи [Supabase CLI](https://supabase.com/docs/guides/cli), войди в аккаунт и привяжи проект из корня репозитория:

   ```text
   supabase login
   supabase link --project-ref ИДЕНТИФИКАТОР_ПРОЕКТА
   supabase functions deploy study-assistant
   ```

   Идентификатор проекта есть в его URL: в `https://ИДЕНТИФИКАТОР.supabase.co`. Функция `study-assistant` настроена требовать действующую сессию Supabase (`verify_jwt = true`).

### 3. Опубликуй сайт

Опубликуй содержимое репозитория через GitHub Pages. Убедись, что `config.js` с URL и публичным ключом Supabase включён в публикацию. Переменная Gemini хранится отдельно в Supabase и никогда не публикуется. После настройки проверь создание пользователя, вход, объяснение задачи, поиск видео и тест.

## Возможности

- Меню для перехода между четвертными оценками и помощником по учёбе; на мобильном экране меню сворачивается.
- Расчёт среднего балла и примерной четвертной оценки, подсказки для желаемой оценки, распознавание оценок с фото.
- Регистрация по электронной почте, вход и выход через Supabase Auth.
- Пошаговые объяснения Gemini, тест из четырёх вариантов с обратной связью, поиск объясняющего видео на YouTube по запросу.
- Ключ Gemini используется только серверной функцией. Ключ правильного ответа передаётся только в зашифрованном серверном токене и проверяется сервером; токен действует 30 минут. Если проект или функция не настроены, интерфейс показывает понятное сообщение вместо фиктивного ответа.
